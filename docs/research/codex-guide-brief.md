## 内容结构（按此写）

1. **顶部**：VibeHub 是什么——一句话：「给零基础学员一条『作品从做出来到公开上线』的完整通道，给老师一个看得见、审得了、能汇总的管理台。」
2. **三个角色速览**（小卡片）：学员 / 老师 / 访客各关心什么。
3. **老师怎么用**（配图 04→02→03）：
   - 打开控制台 `https://hub.supermind-ai.cn`，用邀请码登录（老师码由管理员发放，登录无需密码）
   - 「邀请码管理」批量生成学员码、导出 CSV 发给学员（图 04）
   - 「课程总览」一眼看全班进度、谁卡住了（图 02）
   - 「审核台」预览学员作品、看 AI 诊断、点「审核并发布」或「退回修改」（图 03）
4. **学员怎么用**（配图 05 + 命令）：
   - 在自己的 AI 工具（Claude Code / Codex / WorkBuddy）里，用老师发的邀请码接入：
     ```
     vibehub bind CAMP-XXXX
     ```
   - 做好网页后一句命令发布：
     ```
     vibehub deploy --summary "本次做了什么"
     ```
   - `vibehub status` 看状态和 AI 诊断；作品有独立网址和二维码，可分享（图 05）
   - 强调「提交≠上线，老师审核通过后才有正式网址」
5. **访客看什么**（配图 06）：课程作品集合页，每个作品有独立入口。
6. **底部**：一句话说明技术特点（作品是纯静态站+平台托管数据能力，学员不碰服务器；发布前老师审核；AI 诊断的完成度可解释）。

## 风格要求（重要）

- 用 **frontend-design** 的水准，暖色系，**跟产品本身的设计语言一致**（配色直接用产品 token）：
  `--canvas:#f8f5ef; --surface:#fbf9f5; --ink:#242321; --ink-soft:#73716d; --line:#ded9d0; --coral:#ed624a; --blue:#3978bd`，字体 `"PingFang SC", system-ui`。珊瑚红只用于强调关键点，别滥用。
- 单个 HTML 文件，CSS 内联在 `<style>` 里，不依赖任何外部 CDN/JS。
- 截图用相对路径 `assets/xxx.png`，加圆角+细边框+轻阴影，`max-width:100%` 响应式，配简短图注。
- 移动端可读（响应式，窄屏不横向滚动）。
- **不要在 HTML 里写任何真实邀请码**（用 `CAMP-XXXX` 占位）——这份说明可能会公开分享。
- 中文。
