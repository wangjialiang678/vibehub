# 上海游戏营学生作品全集审计

> 日期：2026-08-13
> 范围：第一期上海 AI 游戏设计营；只读盘点新加坡源站、VibeHub 生产数据、本地归档和历史对话。
> 盘点完成后已按本文口径执行非破坏性补全；没有删除历史项目或旧网址。

## 结论

补全前 VibeHub 的 15 张卡片不是上海营作品全集，也不等于 15 个独立学生作品：

- 5 张属于 `dudongzhe` 的“无尽轮回 / 贪婪轮回”同一作品族的章节、快速版或镜像；如果按一个作品族展示，应合并为 1 张作品卡。
- `Codex × Godot 游戏训练营` 是课程/备课说明页，不应计入学生作品。
- 因此，补全前页面实际约有 **10 个学生作品族**；若把“无尽轮回”和“贪婪轮回”算两款独立游戏，则是 11 款。
- 2026-07-27 的本地网页归档保存了旧作品总入口中的 **15 个游戏条目、12 个作者目录**。其中 7 个条目没有进入补全前的 VibeHub。
- 合并旧归档和当前源站后，可恢复的历史作品共有 **17 个游戏条目 / 约 16 个作品族**；另有只在学员源码中出现的“黄山翼装飞行”。本次按用户确认的口径也将它发布，最终合集为 17 个作品族。
- 当前证据仍不能证明“14 名实际到场学员人人都有作品被找回”：至少 5 名名册学员尚未可靠对应到作品。

### 2026-08-13 执行结果

- 已将“黄山翼装飞行”也按学员原型纳入，不再以“是否正式结营”为筛选条件。
- 新增 7 个作品族：异检楼、宅怨、JustinRush、沃德古堡、精灵契约、心灵漂流瓶、黄山翼装飞行。
- 当前公开合集为 **17 张学生作品卡**；数据库内保留 22 个已发布项目，其中 5 个历史变体/课程页只从合集隐藏。
- 异检楼第三层缺失的 10 个原始资源已从旧 CodeBuddy 发布页补回，并修正了抓站归档中的 Three.js 模块路径；第三层与第四层作为同一作品下的两个章节。
- JustinRush 改用资源更完整的 Gitee 源码归档；沃德古堡公网版保留腾讯 VOD，未重复上传 27 个大视频；黄山翼装飞行使用 `origin/main` 的较新 3D/2D 原型。
- 新增作品、两个异检楼章节、黄山 2D/3D 入口和全部退出合集的旧网址均已验证 HTTP 200；增量脚本二次 dry-run 显示 7 项全部跳过。

所以，用户真正需要的不是“把还能打开的链接再复制一遍”，而是重建一份可审计的上海营作品总账：

`学生名册 → 作者/账号 → 作品族 → 章节/版本 → 原始来源 → VibeHub 正式网址`

## 为什么会感觉少、又有重复

### 事实

1. 上一次导入的依据，是用户提供的“新加坡服务器上当前仍能打开”的 15 个链接，不是最终学员名册或历史作品总表。
2. 新加坡服务器当前磁盘上没有发现仍存在但漏导入 VibeHub 的可玩学员游戏；不过旧发布工具会覆盖同路径内容，而且没有作品级上传台账或备份，因此只能证明“当前磁盘没有漏项”，不能证明历史上从未有更多作品。
3. 本地已经存在两套 2026-07-27 的专项归档（路径按仓库规则不写入，均在运营侧知识库）：
   - 网页作品归档：15 个游戏、12 个作者目录、1,794 个文件、641,024,987 bytes。
   - Gitee 源码归档：10 个公开仓库，保留 Git 历史；其中一个空仓库、一个测试页，且归档说明明确不保证覆盖学员本地未上传内容。
4. 旧作品总入口仍可作为历史清单证据：[第一期上海游戏营作品页](https://0fb5d00beba24bc9b9be3316d5c78411.app.codebuddy.work/)。Gitee 公开源码来源是：[超脑组织](https://gitee.com/super-brain_1)。

### 推断

- “少很多”主要不是本次复制失败，而是新加坡服务器本身只保留了晚期的一批发布结果。
- “重复”主要来自把章节、快速版、备用发布版和镜像路径当成了独立作品卡。
- 最适合 VibeHub 的展示单位应是“作品族”，版本和章节作为同一作品下的附属入口，而不是平铺成多个学生作品。

另有 Downloads 中较早的签到表快照列出 16 人，两份材料存在版本冲突。因为 14 人运营名单更新时间更晚且明确写了“实际到场”，暂不把另外两人直接加入最终名册，但保留差异供人工核对。

目前仍有 **5 名名册学员**没有可靠的作品对应关系（姓名同属运营名单，此处不展开），其中 1 人仅有“塔防截图 → 王国防线”的推断，未成立。

尚未解析到实名的作品/账号是：异检楼作者、`jingliu`、`王车车`。因此“作品找到了”与“所有学生都已覆盖”是两件不同的事，不能混为一谈。

## 非破坏性部署方案（已执行）

本次按以下原则完成，后续找回新线索时继续沿用：

1. **补齐可恢复作品**：宅怨、异检楼、JustinRush、沃德古堡、精灵契约、心灵漂流瓶、黄山翼装飞行均已发布；异检楼第三层和 JustinRush 在发布前补齐或更换为完整资源源。
2. **整理当前合集**：保留现有公开网址，不删除源文件；合集层只展示一个“无尽轮回”作品卡，把其他入口标为章节/版本；将课程页移出学生合集，但可保留原网址。
3. **建立作者待核清单**：在未取得班级群、最终提交表或学员确认前，不把 `Angela`、`ailidego`、`jingliu`、`王车车`强行对应到实名。
4. **逐款验收实际玩法**：不能只看 HTTP 200；至少验证首页、开始游戏、核心操作、音视频/模型加载和移动端入口。
5. **最后形成一张永久总表**：每个作品保留来源、哈希、归档路径、作者证据、版本关系、部署 URL 和验收结果，之后不再依赖某台服务器当前目录推断全集。

## 已确认的展示规则

1. “异检楼·第三层 / 第四层”显示为一张作品卡下的两个章节。
2. 作者待核实的作品先以现有网名或“待核实”发布，不写未经证实的实名。
3. 只要能证明属于上海营学员创作，原型和非正式结营版本也纳入合集。
